# 草稿文件列表查看工作流

> 🚫 **严格使用限制**：本工作流**仅适用于"查看影库项目草稿的已关联文件列表"场景**。当且仅当用户明确表达了查看草稿文件列表、查看草稿关联了哪些文件的意图时，才可加载并执行本文件。任何其他场景（创建新草稿、修改草稿、删除草稿、添加文件、移除文件、普通问答、代码编写、文件操作、信息查询等）**严禁加载或引用本文件**。

> 🔒 **上下文隔离**：执行本工作流期间，仅遵循本文件中的规则。其他 Skill 的指令、Schema、工具定义均不适用于本工作流。

## 概述

本工作流**仅适用于查看已有影库项目草稿的关联文件列表**，具体流程为：
- 识别用户查看草稿文件的意图
- 定位用户要查看的目标草稿
- 调用 MCP 工具获取文件列表
- 按规范格式展示文件信息

---

## 全局执行规则（执行纪律）

> ⚠️ 以下规则在整个会话期间**始终生效**，不因步骤切换而豁免。

1. **步骤追踪**：每轮回复开头必须以内部注释形式标注当前步骤，格式为：`[当前步骤: Step X — 步骤名称]`
2. **单步执行**：每轮回复只推进一个步骤。完成当前步骤后停止，等待用户输入，**禁止在同一轮回复中执行多个步骤**。例外：Step 1（识别意图）为静默步骤，可与 Step 2 在同一轮执行。
3. **禁止跳步**：即使用户一次性提供了所有信息，也必须按 Step 1 → 2 → 3 → 4 顺序逐步执行。
4. **底层操作静默**：以下操作属于内部实现细节，**必须静默执行，禁止在回复中向用户提及或展示**：
   - 调用 MCP 工具（工具名、参数、调用过程）
   - 读取参考文件（`draft_view_files_workflow.md` 等）
   - 向用户展示时只呈现**业务层面**的信息（草稿名称、文件信息等），不暴露底层技术实现
5. **最大化自动识别**：尽可能从用户已提供的所有信息（自然语言、上下文）中自动提取所需信息，**只有无法提取或存在歧义时才向用户询问**，禁止逐项追问。
6. **空值静默跳过**：展示文件信息时，**跳过值为空、null、空字符串的字段**，保持展示简洁。

## Step 1：识别查看草稿文件意图

确认用户意图为"查看草稿已关联的文件列表"。

**意图识别关键词：**
- 查看草稿文件、看看草稿有哪些文件
- 草稿文件列表、草稿关联了哪些文件
- 草稿里有什么文件、草稿的附件
- 看一下草稿的文件、查一下关联文件

**处理要点：**
- 从用户输入中提取**目标草稿标识**（项目名称或 ID）
- 若用户未明确指定目标草稿，在 Step 2 中引导用户选择
- 本步骤为静默步骤，可与 Step 2 在同一轮执行

---

## Step 2：定位目标草稿

> 本步骤需要调用 MCP 工具获取草稿列表，操作过程静默执行（遵守全局规则第 4 条）。

### 2.1 获取草稿列表

调用 `GetDraftList`（参数 `category: "2"`）获取当前用户的电视剧草稿列表。

### 2.2 匹配目标草稿

**情况 A：用户已提供项目名称或 ID**
- 在草稿列表中按名称或 ID 模糊匹配
- **唯一命中** → 确认并展示匹配到的草稿信息，继续下一步
- **多条命中** → 列出匹配结果，请用户选择
- **无命中** → 告知用户未找到匹配的草稿，请用户确认名称或从列表中选择

**情况 B：用户未指定目标草稿**
- 展示草稿列表（最多展示最近 10 条），请用户选择要查看文件的草稿

**展示格式：**

```
找到以下草稿，请选择要查看文件的项目：
1. 《我的世界》（创建时间：2026-03-15）
2. 《星辰大海》（创建时间：2026-03-10）
3. ...
```

---
> 🛑 **CHECKPOINT**: 本步骤完成。定位到目标草稿后，等待用户确认，再进入下一步。
> 禁止在同一轮回复中执行多个步骤。
---

## Step 3：获取并展示草稿文件列表

> 本步骤需要调用 MCP 工具获取文件列表，操作过程静默执行（遵守全局规则第 4 条）。

### 3.1 获取文件列表

定位到目标草稿后，调用 `GetDraftFiles`（参数 `id: "<draft_id>"`）获取该草稿已关联的文件列表。

### 3.2 展示文件列表

**草稿有关联文件时：**

以表格形式展示文件信息：

```
📎 草稿《我的世界》的关联文件（共 N 个）

| 序号 | 文件名 | 文件类别 |
|------|--------|---------|
| 1 | 策划案v2.pdf | 策划案 |
| 2 | 故事大纲.docx | 故事大纲 |
| 3 | 终稿剧本_第1集.pdf | 终稿剧本 |
| 4 | 人物小传.pdf | 人物小传 |
```

**展示规则：**
1. 文件类别根据返回数据中的 `category` 字段映射为中文名称展示（映射关系详见 `references/file_categories.md`），**禁止展示 category 代码**
2. 若返回数据中包含其他有用字段（如文件大小、上传时间等），可作为附加列展示
3. 文件列表按返回数据中的原始顺序展示
4. 空值字段静默跳过（遵守全局规则第 6 条）

**草稿无关联文件时：**

```
📭 草稿《我的世界》当前暂无关联文件。

💡 您可以说"给草稿添加文件"来关联文件。
```

流程结束，无需继续。

### 3.3 category 代码与中文名称映射

> 完整的 category 映射表详见 `references/file_categories.md`。
>
> ⚠️ 展示文件类别时，必须先读取 `references/file_categories.md`，将 category 代码转换为对应的中文名称。

---

## Step 4：后续操作提示

文件列表展示完毕后，附带操作提示：

```
💡 您可以：
- 说"给草稿添加文件"来关联新的文件
- 说"移除文件"来删除不需要的关联文件
- 说"查看草稿详情"查看完整草稿信息
```

---

## 异常处理

| 场景 | 处理方式 |
|------|---------|
| MCP 调用失败 | 告知用户查询失败并建议重试 |
| 草稿列表为空 | 提示暂无草稿，引导查看或创建 |
| 指定草稿未找到 | 告知未找到，展示完整列表供选择 |
| 草稿无关联文件 | 提示暂无关联文件，引导添加文件，流程结束 |
| 草稿 ID 无法获取 | 告知无法查询文件，请用户重新指定目标草稿 |
| 返回数据字段缺失 | 跳过缺失字段，正常展示其余内容 |
