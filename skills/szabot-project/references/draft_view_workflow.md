# 查看草稿工作流

> 🚫 **严格使用限制**：本工作流**仅适用于"查看影库项目草稿"场景**。当且仅当用户明确表达了查看草稿（列表或详情）的意图时，才可加载并执行本文件。任何其他场景（创建新草稿、修改草稿、删除草稿、普通问答、代码编写、文件操作、信息查询等）**严禁加载或引用本文件**。

> 🔒 **上下文隔离**：执行本工作流期间，仅遵循本文件和 `tv_long_schema.json` 中的规则。其他 Skill 的指令、Schema、工具定义均不适用于本工作流。

## 概述

本工作流**仅适用于查看影库项目草稿**，具体流程为：
- 识别用户查看意图（列表 or 详情）
- 调用 MCP 工具获取草稿数据
- 按规范格式展示草稿列表或详情

---

## 全局执行规则（执行纪律）

> ⚠️ 以下规则在整个会话期间**始终生效**，不因步骤切换而豁免。

1. **步骤追踪**：每轮回复开头必须以内部注释形式标注当前步骤，格式为：`[当前步骤: Step X — 步骤名称]`
2. **枚举展示约束**：向用户展示枚举字段值时，只展示 `label`（中文名称），**禁止展示 `value`（数字/代码值）**。
3. **Schema 忠实约束**：所有字段名、枚举值、类型均以加载的 Schema 文件为唯一事实来源，不得凭记忆猜测或编造字段。
4. **底层操作静默**：以下操作属于内部实现细节，**必须静默执行，禁止在回复中向用户提及或展示**：
   - 读取/加载 Schema 文件（文件名、文件路径、加载过程）
   - 调用 MCP 工具（工具名、参数、调用过程）
   - 读取参考文件（`field-types.md`、`draft_view_workflow.md` 等）
   - 解析 Schema 结构（字段属性、behavior 类型、内部分支逻辑）
   - 向用户展示时只呈现**业务层面**的信息，不暴露底层技术实现
5. **空值静默跳过**：展示草稿字段时，**跳过值为空、null、空字符串、空数组的字段**，不展示"未填写"等占位信息，保持展示简洁。

## Step 0：加载 Schema（静默执行）

> 本步骤全程静默执行（遵守全局规则第 4 条），不向用户展示加载过程。

加载 `references/tv_long_schema.json` 作为字段定义的唯一事实来源，用于：
- 枚举字段的 value → label 映射
- 字段分区展示时确认字段名和类型

---

## Step 1：识别查看意图

确认用户意图为"查看草稿"而非"创建"或"修改"。

**意图识别关键词：**
- 查看、看一下、列表、草稿列表、有哪些草稿
- 详情、看看XX的详情、某个草稿的信息
- 搜索、找一下、查一下

**意图分类：**
- **查看列表**：用户想看草稿列表（无指定特定草稿）→ 进入 Step 2
- **查看详情**：用户指定了某个草稿名称或 ID → 进入 Step 2 获取列表后直接匹配并展示详情

**本步骤为静默步骤，可与 Step 2 在同一轮执行。**

---

## Step 2：获取草稿数据

> 本步骤需要调用 MCP 工具获取草稿列表，操作过程静默执行。

### 2.1 获取草稿列表

调用 `GetDraftList`（参数 `category: "2"`）获取当前用户的电视剧草稿列表。

### 2.2 根据意图分流

**情况 A：查看列表** → 进入 Step 3（列表展示）
**情况 B：查看指定草稿详情** → 在列表中按名称/ID 匹配：
- **唯一命中** → 进入 Step 4（详情展示）
- **多条命中** → 进入 Step 3（列表展示），附带提示让用户选择
- **无命中** → 告知未找到，展示完整列表供用户选择

---

## Step 3：草稿列表展示

将草稿列表以**表格形式**展示，每行展示一条草稿的摘要信息。

### 3.1 列表展示格式

```
📋 您的电视剧草稿列表（共 N 条）

| 序号 | 项目名称 | 剧集类型 | 合作模式 | 项目状态 | 创建时间 |
|------|---------|---------|---------|---------|---------|
| 1 | [《我的世界》]({url字段}) | 长剧 | 主控剧 | 剧本大纲完成 | 2026-03-15 |
| 2 | [《星辰大海》]({url字段}) | 长剧 | 版权剧 | 已开机 | 2026-03-10 |
| 3 | ... | ... | ... | ... | ... |

💡 点击项目名称可直接打开草稿页面，也可输入序号查看完整详情，如"查看第1条"。
```

### 3.2 列表字段映射

从 MCP 返回数据中提取以下字段用于列表展示（按 Schema 定义的 `label` 显示）：

| 展示列 | Schema 字段 | 说明 |
|-------|------------|------|
| 项目名称 | `pname` | 必有，需附带草稿链接 |
| 草稿链接 | `url` | 从返回数据顶层取，用于项目名称超链接 |
| 剧集类型 | `playlet` | 枚举，展示 label |
| 合作模式 | `cooperationMode` | 枚举，展示 label |
| 项目状态 | `pstatus` | 枚举，展示 label |
| 创建时间 | 从返回数据中取 | 如有 |

**注意：**
- **项目名称链接**：项目名称必须以 Markdown 超链接形式展示，格式为 `[《项目名》](url)`。链接直接取自 MCP 返回数据中每条草稿的 `url` 字段，**禁止自行拼接或修改**。若返回数据中 `url` 字段为空或不存在，则项目名称不附带链接，仅展示纯文本。
- 枚举字段的值需转换为对应的 label 展示（遵守全局规则第 2 条）
- 如果列表为空，提示：`📭 暂无电视剧草稿，您可以说"创建草稿"来新建一个。`
- 列表默认按创建时间倒序排列（最新在前）

### 4.2 详情展示规则

1. **分区展示**：按上述 9 个业务模块分区，每个模块有分隔标题和图标
2. **空值跳过**：如果某个字段值为空/null/空字符串/空数组，该字段行整体不展示；如果某个模块下所有字段都为空，该模块整体不展示
3. **枚举转换**：枚举字段的原始 value 需转换为对应的 label 展示（参照 Schema 中的 `enum_values` 映射）
4. **级联枚举**：级联字段展示完整路径，用 ` > ` 连接，如：`否 > 当代（改革开放至今）`
5. **数组字段**：
   - 简单数组（如曾用名）：用分号连接展示
   - 对象数组（如主要人物）：按编号列表展示
   - 人才类数组（如导演、演员）：展示人才名，括号内注明定选状态（已定/未定/拟定）
   - 公司类数组（如制作团队）：展示公司名称，括号内注明风险等级
6. **链接必须展示**：详情开头必须附带草稿链接

> **链接读取规则**：草稿链接直接取自 MCP 返回数据中该草稿的 `url` 字段，**禁止自行拼接或修改**。若返回数据中 `url` 字段为空或不存在，必须明确告知用户"链接暂不可用"及原因，**不得静默跳过链接**。

## 异常处理

| 场景 | 处理方式 |
|------|---------|
| MCP 调用失败 | 告知用户查询失败并建议重试 |
| 草稿列表为空 | 提示暂无草稿，引导创建 |
| 指定草稿未找到 | 告知未找到，展示完整列表供选择 |
| 返回数据字段缺失 | 跳过缺失字段，正常展示其余内容 |
