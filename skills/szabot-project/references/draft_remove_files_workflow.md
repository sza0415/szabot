# 草稿移除文件工作流

> 🚫 **严格使用限制**：本工作流**仅适用于"从影库项目草稿中移除/删除关联文件"场景**。当且仅当用户明确表达了从草稿移除文件、删除草稿关联文件的意图时，才可加载并执行本文件。任何其他场景（创建新草稿、修改草稿、删除草稿、添加文件、查看草稿、普通问答、代码编写、文件操作、信息查询等）**严禁加载或引用本文件**。

> 🔒 **上下文隔离**：执行本工作流期间，仅遵循本文件中的规则。其他 Skill 的指令、Schema、工具定义均不适用于本工作流。

## 概述

本工作流**仅适用于从已有的影库项目草稿中移除关联文件**，具体流程为：
- 识别用户移除草稿文件的意图
- 定位用户要操作的目标草稿
- 展示已关联文件并确认要移除的文件
- 二次确认移除操作
- 调用 MCP 工具 `DeleteDraftFile` 逐个执行移除
- 反馈用户操作结果

---

## 全局执行规则（执行纪律）

> ⚠️ 以下规则在整个会话期间**始终生效**，不因步骤切换而豁免。

1. **步骤追踪**：每轮回复开头必须以内部注释形式标注当前步骤，格式为：`[当前步骤: Step X — 步骤名称]`
2. **单步执行**：每轮回复只推进一个步骤。完成当前步骤后停止，等待用户输入，**禁止在同一轮回复中执行多个步骤**。例外：Step 1（识别意图）为静默步骤，可与 Step 2 在同一轮执行。
3. **禁止跳步**：即使用户一次性提供了所有信息，也必须按 Step 1 → 2 → 3 → 4 → 5 → 6 顺序逐步确认。
4. **底层操作静默**：以下操作属于内部实现细节，**必须静默执行，禁止在回复中向用户提及或展示**：
   - 调用 MCP 工具（工具名、参数、调用过程）
   - 读取参考文件（`draft_remove_files_workflow.md` 等）
   - 向用户展示时只呈现**业务层面**的信息（草稿名称、文件信息、操作结果等），不暴露底层技术实现
5. **最大化自动识别**：尽可能从用户已提供的所有信息（自然语言、文件、上下文）中自动提取所需信息，**只有无法提取或存在歧义时才向用户询问**，禁止逐项追问。
6. **移除不可逆原则**：文件移除后无法自动恢复关联，必须在执行前进行二次确认，确保用户充分知悉后果。

## Step 1：识别移除文件意图

确认用户意图为"从草稿移除/删除关联文件"。

**意图识别关键词：**
- 移除文件、删除文件、去掉文件、删掉附件
- 把 XX 文件从草稿里删了、草稿文件删掉
- 移除草稿关联的文件、取消文件关联
- 草稿里那个 XX 文件不要了

**处理要点：**
- 从用户输入中提取两类信息：**目标草稿标识**（项目名称或 ID）和 **要移除的文件标识**（文件名或描述）
- 若用户未明确指定目标草稿，在 Step 2 中引导用户选择
- 若用户未明确指定要移除的文件，在 Step 3 中展示文件列表供选择
- 本步骤为静默步骤，可与 Step 2 在同一轮执行

---

## Step 2：定位目标草稿

> 本步骤需要调用 MCP 工具获取草稿列表，操作过程静默执行（遵守全局规则第 4 条）。

### 2.1 获取草稿列表

调用 `GetDraftList`（参数 `category: "2"`）获取当前用户的电视剧草稿列表。

### 2.2 匹配目标草稿

**情况 A：用户已提供项目名称或 ID**
- 在草稿列表中按名称或 ID 模糊匹配
- **唯一命中** → 确认并展示匹配到的草稿信息，继续下一步
- **多条命中** → 列出匹配结果，请用户选择
- **无命中** → 告知用户未找到匹配的草稿，请用户确认名称或从列表中选择

**情况 B：用户未指定目标草稿**
- 展示草稿列表（最多展示最近 10 条），请用户选择要操作的草稿

**展示格式：**

```
找到以下草稿，请选择要移除文件的项目：
1. 《我的世界》（创建时间：2026-03-15）
2. 《星辰大海》（创建时间：2026-03-10）
3. ...
```

---
> 🛑 **CHECKPOINT**: 本步骤完成。定位到目标草稿后，等待用户确认，再进入下一步。
> 禁止在同一轮回复中执行多个步骤。
---

## Step 3：展示已关联文件并确认要移除的文件

> 本步骤需要调用 MCP 工具获取文件列表，操作过程静默执行（遵守全局规则第 4 条）。

### 3.1 获取已关联文件列表

定位到目标草稿后，调用 `GetDraftFiles`（参数 `id: "<draft_id>"`）获取该草稿已关联的文件列表。

**若草稿暂无关联文件：**

```
草稿《我的世界》当前暂无关联文件，无需移除。
```

流程结束，无需继续。

### 3.2 展示文件列表

将已关联的文件以编号列表形式展示，供用户选择要移除的文件。

**文件类别显示**：文件列表中的"文件类别"列，需将 `category` 代码映射为中文名称，完整的 category 映射表详见 `references/file_categories.md`。

```
草稿《我的世界》当前关联的文件如下：

| 序号 | 文件名 | 文件类别 |
|------|--------|---------|
| 1 | 策划案v2.pdf | 策划案 |
| 2 | 故事大纲.docx | 故事大纲 |
| 3 | 终稿剧本_第1集.pdf | 终稿剧本 |

请输入要移除的文件序号（多个用空格或逗号分隔，输入"全部"移除所有文件）。
```

### 3.3 匹配用户选择

**情况 A：用户在 Step 1 中已指定要移除的文件**
- 按文件名关键词在已关联文件列表中模糊匹配
- **唯一命中** → 直接标记为待移除，展示确认信息
- **多条命中** → 列出匹配结果，请用户确认要移除哪些
- **无命中** → 告知用户指定的文件不在关联列表中，展示完整列表供选择

**情况 B：用户输入序号**
- 解析序号，映射到对应文件

**情况 C：用户输入"全部"**
- 标记所有文件为待移除

---
> 🛑 **CHECKPOINT**: 本步骤完成。确认要移除的文件后，等待用户确认，再进入下一步。
> 禁止在同一轮回复中执行多个步骤。
---

## Step 4：二次确认

> ⚠️ **文件移除后无法自动恢复关联**，必须在此步骤进行二次确认。禁止跳过本步骤直接执行移除。

向用户展示即将移除的文件信息并请求确认：

**移除单个文件：**

```
⚠️ 确认要从草稿《我的世界》中移除以下文件吗？

  - 📄 策划案v2.pdf（策划案）

移除后文件关联将解除，如需重新关联需再次添加。
请回复"确认移除"执行操作，或回复"取消"放弃。
```

**移除多个文件：**

```
⚠️ 确认要从草稿《我的世界》中移除以下 3 个文件吗？

| 序号 | 文件名 | 文件类别 |
|------|--------|---------|
| 1 | 策划案v2.pdf | 策划案 |
| 2 | 故事大纲.docx | 故事大纲 |
| 3 | 终稿剧本_第1集.pdf | 终稿剧本 |

移除后文件关联将解除，如需重新关联需再次添加。
请回复"确认移除"执行操作，或回复"取消"放弃。
```

**用户回复处理：**
- 用户回复"确认移除"、"确认"、"确定"、"是"等肯定性回复 → 进入 Step 5
- 用户回复"取消"、"算了"、"不删了"等否定性回复 → 告知已取消操作，流程结束
- 用户回复其他内容（如修改选择）→ 回到 Step 3 重新选择

---
> 🛑 **CHECKPOINT**: 本步骤完成。等待用户确认或取消，再进入下一步。
> 禁止在同一轮回复中执行多个步骤。
---

## Step 5：调用 MCP 移除文件

> 本步骤全程静默执行（遵守全局规则第 4 条），不向用户展示工具名、参数或调用过程。

### 5.1 逐个执行移除

`DeleteDraftFile` 工具每次仅能移除一个文件，参数格式：

```json
{
  "id": "<草稿ID>",
  "file_id": "<文件ID>"
}
```

**要点：**
- `id`：目标草稿的 ID（从 Step 2 获取）
- `file_id`：要移除的文件的唯一标识（从 Step 3 的文件列表中获取）
- 若需移除多个文件，**逐个调用** `DeleteDraftFile`，每次传入一个 `file_id`
- 记录每次调用的结果（成功/失败）

### 5.2 错误处理

**如单次调用失败：**
1. 记录失败的文件及错误信息
2. 继续执行剩余文件的移除（不因单个失败而中断整体流程）
3. 所有文件处理完毕后，在 Step 6 中汇总反馈

---

## Step 6：反馈用户

根据调用结果告知用户：

**全部成功：**

```
✅ 文件移除成功！

项目草稿：《我的世界》
已移除文件：
  - 📄 策划案v2.pdf（策划案）
  - 📄 故事大纲.docx（故事大纲）

💡 如需重新关联文件，可以说"给草稿添加文件"。
```

**全部失败：**

```
❌ 文件移除失败
错误信息：[MCP 返回的错误详情]
建议：[根据错误类型给出修复建议]
```

**部分失败（多个文件时，部分成功部分失败）：**

```
⚠️ 部分文件移除完成

✅ 已成功移除：
  - 📄 策划案v2.pdf（策划案）

❌ 移除失败：
  - 📄 故事大纲.docx — [错误原因]

建议：[修复建议]
```

## 异常处理

| 场景 | 处理方式 |
|------|---------|
| MCP 调用失败 | 告知用户移除失败并建议重试 |
| 草稿列表为空 | 提示暂无草稿，引导查看或创建 |
| 指定草稿未找到 | 告知未找到，展示完整列表供选择 |
| 草稿无关联文件 | 提示暂无关联文件，无需移除，流程结束 |
| 用户取消移除 | 告知已取消操作，无副作用 |
| 草稿 ID 无法获取 | 告知无法执行移除，请用户重新指定目标草稿 |
| file_id 无法获取 | 告知无法定位文件，请用户重新选择 |
| 单个文件移除失败（多文件场景） | 记录失败，继续移除其余文件，最终汇总反馈 |
