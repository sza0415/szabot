## 匹配规则

1. 对文件名进行关键词扫描，**优先匹配子类型**：如文件名含"剧本"且含"终稿"→ 使用 `123129307+123134052`；含"剧本"且含"定稿"→ 使用 `123129307+123134051`
2. 若仅匹配到父类型关键词（如仅含"剧本"无"终稿/定稿"）→ 使用父类型 `123129307`
3. 若文件名未匹配到任何关键词 → **询问用户选择文件类别**，展示所有可选类型供用户选择

### 子类型双 category 传值规则

剧本的三个子类型（全集定稿剧本、终稿剧本、其他版本）在传值时必须同时携带**父类型 + 子类型**两个 category ID，用 `+` 拼接：

| 子类型 | 传值格式 |
|--------|---------|
| 全集定稿剧本 | `123129307+123134051` |
| 终稿剧本 | `123129307+123134052` |
| 其他版本 | `123129307+123134050` |

> ⚠️ 仅这三个子类型需要双 category 传值，其他所有类型（包括父类型"剧本"本身）均为单个 category ID。

## 常见错误

1. **无关键词文件必须询问**：当文件名未包含任何预设关键词时，**必须**进入用户选择流程，展示全部20个选项。**禁止**使用默认值、历史值或猜测的 category（例如，不得因为上一个文件是"策划案"而将无关键词文件也默认为策划案）。

2. **子类型判定遗漏**：必须严格按照"子类型优先匹配"规则执行。若文件名同时包含"剧本"和"终稿"，必须使用 `123129307+123134052`（终稿剧本），而非仅传父类型 `123129307`（剧本）。子类型必须使用"父+子"双 category 格式传值。

3. **关键词扫描不完整**：文件名中的关键词可能是中文全角、半角或包含符号变体。扫描时应进行大小写不敏感、全半角不敏感的匹配，确保"策划案"、"策划案"、"策划案"等均能识别。

4. **category 误用**：每个 category 代码对应唯一类型，严禁混用。例如，`123129309` 仅用于"策划案"，不得用于"故事大纲"等其它类型。

5. **用户选择流程跳过**：任何情况下，只要文件名未匹配到关键词，就必须触发用户选择流程。不得以"用户可能嫌麻烦"为由自动选择默认值。
