# 网络搜索 Skill

网络搜索 Skill 提供互联网搜索能力，通过 MCP 服务 `szbot_web_search_svr` 调用 `mcp_web_search` 工具，获取实时网络信息。

> ⚠️ **优先级说明**：涉及影视综项目信息（项目、排播、人才、舆情、合同等）时，必须**优先使用 `szabot-copilot` 查询影库内部数据**。当内部数据有限、不够丰富、或内部搜索结果非精确匹配时，应**主动使用本 Skill 搜索公开信息补充更丰富的内容和最新动态**，而非仅在数据完全缺失时才兜底。不要将网络搜索作为影视综信息的首选查询方式。

> 💡 **与 `szabot-copilot` 内 `search_web` 的关系**：`szabot-copilot` 的工具链中包含 `search_web`（属于 `szabot_tools`），与本 Skill 的 `mcp_web_search` 底层为同一搜索能力。当已在 `szabot-copilot` 工作流中时，直接使用 `search_web` 即可；本 Skill 适用于**非 copilot 工作流**的独立网络搜索场景（如通用问题、非影视综查询等）。

适用场景包括：
- **影库内部数据有限或搜索结果非精确匹配时**的主动补充完善（如热度对比、口碑舆情、演员/导演最新动态、项目最新进展、模糊匹配结果的信息验证与补全等）
- 查询最新新闻、资讯、事件动态
- 获取百科知识、术语定义
- 搜索特定主题的公开资料
- 获取实时数据（如股价、天气、赛事结果等）

本 Skill 主要负责**路由、优先级和执行流程约束**。

## 一、执行流程（强约束）

1. **先加载 Skill**
   - 当用户问题需要网络搜索获取实时信息、最新资讯，或需要验证/补充信息时，应加载本 Skill。

2. **加载后先调用 MCP 服务**
   - 加载本 Skill 后，不要直接凭记忆回答。
   - 应先连接网络搜索 MCP 服务，拉取当前服务的工具 map / tool list。
   - 典型验证方式：`mcporter list szbot_web_search_svr`

3. **优先识别 `mcp_web_search`**
   - 若工具 map 中存在 `mcp_web_search`，则它是默认首选入口。
   - 后续执行时，应优先遵循它的**工具描述**与**额外信息**。
   - Skill 本身只定义入口与顺序，工具层定义主要业务知识与回答约束。

4. **默认调用 `mcp_web_search`**
   - 命中网络搜索场景后，默认先调用：`mcp_web_search(keyword)`。

5. **允许绕过的场景**
   - `mcp_web_search` 明确返回无数据；
   - `mcp_web_search` 明确返回无权限；
   - 用户明确要求使用其他搜索方式。

6. **MCP 服务不可用时的回退策略（强制）**
   - 当 `szbot_web_search_svr` 连接失败、`mcp_web_search` 报错（如"Brave API 未配置"、服务超时等）时，**不要直接放弃并告知用户搜索不可用**
   - 回退顺序：
     1. 尝试通过 `szabot-copilot` 的 `search_web`（`szabot_tools`）执行相同搜索（底层同一能力）
     2. 若仍失败，基于已有知识尽可能回答，并明确标注"网络搜索暂不可用，以下信息基于已有知识，可能不是最新"
   - **禁止**仅输出"网络搜索不可用"就结束对话

## 二、快速开始

### 验证 MCP 服务

```bash
mcporter list szbot_web_search_svr
```

### 调用示例

```bash
mcporter call "szbot_web_search_svr.mcp_web_search(keyword:'今天的热点新闻')"
```

## 三、工具入口说明

使用以下命令查看可用工具：

```bash
mcporter list szbot_web_search_svr
```

获取到网络搜索 MCP 服务的功能列表，然后再选择合适的函数，封装好参数，进行调用。

### 1. `mcp_web_search`（默认首选工具）

**工具描述**：

网络搜索主入口工具。该工具接收用户的搜索查询，通过互联网搜索引擎获取相关结果并返回。适用于需要获取实时信息、最新资讯、知识验证等场景。

**额外信息**：

- **首选级别**：
  - 本 Skill 的一号入口工具。
  - 命中网络搜索场景时，应优先调用此工具。
  - 当加载了本 Skill 并拉取到 tool map 后，若存在该工具，应默认首选它。

- **调用前置流程**：
  - 先加载本 Skill；
  - 再调用 MCP 服务并拉取工具 map；
  - 识别 `mcp_web_search` 后，以该工具的描述和额外信息作为主执行约束；
  - 然后再正式发起搜索调用。

- **适用问题类型**：
  - 最新新闻、热点事件查询；
  - 百科知识、术语定义查询；
  - 实时数据查询（股价、天气、赛事等）；
  - 特定主题的公开资料搜索；
  - 信息验证与补充。

- **输出要求**：
  - 搜索结果应包含来源链接；
  - 回答结尾附带执行时间及数据来源（MCP / 网络搜索等）；
  - 网络数据引用必须附准确链接；

- **关键准确性规则**：
  - 不要引入搜索结果之外的信息；
  - 当搜索结果不足时，应直接说明查询不足，不要编造信息；
  - 多个搜索结果有矛盾时，应标注不同来源的差异。

- **不应做的事**：
  - 不要在未搜索到结果时自行编造；
  - 不要做举例式补充；
  - 不要在数据不存在时进行估算、假设、联想、续写、改写。

## 四、Skill 边界说明

1. 本 Skill 主要负责：
   - 命中场景判断；
   - 优先级路由；
   - MCP 服务调用顺序；
   - `mcp_web_search` 作为默认首选入口的约束。

2. 搜索结果的解析、过滤和排序逻辑，**优先维护在 `mcp_web_search` 的工具描述与额外信息中**。
