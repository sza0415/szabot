# kb_search 字段使用范围参考
本文档详细列出 `kb_search` query 中所有字段及其适用的参数类别。domain_knowledge 取值遵循 `references/kb_recall.md` 取值铁律。

## ⚠️ 调用前两条强制规则

> **规则 1 · 别名 / 简称必须先映射成正式字段名再传参**
>
> 用户提问中常见的简称、别名、口语化叫法（如"播放VV"、"招商收入"、"ROC"、"全网曝光"、"预约人数"等）**都不是合法字段名**，**严禁**直接放进 `condition` / `target` / `rank` / `range`。
>
> 调用步骤：
> 1. 先到下方 **「§0 字段别名 / 简称速查表」** 找到对应的正式字段名；
> 2. 在表中**找不到**时，再扫描下方各分区表的「说明」列里出现的「**简称：xxx**」「**别名：xxx**」标记；
> 3. 如果两处都查不到 → 说明 `kb_search` 不支持该指标，**禁止**自己造字段名（否则后端会静默忽略，返回结果中该字段缺失）；继续看下一条规则。
>
> **规则 2 · `kb_search` 不支持的播放细分指标必须改走 `szabot-data-query` Skill**
>
> 下列播放/曝光/拉新等**细分指标在本工具中没有对应字段**，传上去也查不到，必须改用 `szabot-data-query` 通过中查询：
>
> - 集均VV / 集均播放VV / 集均UV
> - 首集弃剧率 / 留存率
> - 预估VV（小时级）
> - 搜索UV
> - 弹幕量 / 弹幕数 / 弹幕互动数
> - 拉新人数（含品类拉新、新增正价开通等驱动开通指标的细分日增量）
> - 曝光VV / 曝光UV（项目页/精选页/综合页等细分位）
> - 播放时长（项目级日明细）
>
> 详细路由：见 `szabot-data-query` Skill 的 `references/dianshiju/sql_query.md`。
>
> 在 `kb_search` 这一侧，只能查到**项目维度的累计/汇总字段**（如「总播放VV」「正片播放VV」「人均播放时长（分钟）」「周均播放VV」「实际累计预约量」「腾讯最高热度值」等），见下方各表。

## view 视图字段
**重要**：view 视图字段通过 `view` 参数指定，不是 `param` 参数！

**版权视图**：疑似侵权量趋势
**星舟视频视图**：新增预约人数趋势、腾讯最新热度值趋势
**短音视图**：短音爆款视频数日新增趋势、短音话题播放量日新增趋势、短音热点榜数量趋势
**猫眼视图**：猫眼实时热度趋势、猫眼实时热度排名趋势、全网曝光日新增趋势、全网转赞评日新增趋势
**微博视图**：微博话题阅读量日新增趋势、微博话题讨论量趋势、昨日微博指数趋势

### view 参数使用示例
```bash
# 查询版权视图的疑似侵权量趋势
mcporter call 'szabot_tools.kb_search(
  recall_req_list: [{
    domain_knowledge: "影库知识库-ES-0",
    query: {
      condition: [{"项目ID": ["6057"]}],
      view: {"版权视图": {"param": "", "includes": ["疑似侵权量趋势"]}}
    }
  }]
)' --output json

# 查询星舟视频视图的热度趋势
mcporter call 'szabot_tools.kb_search(
  recall_req_list: [{
    domain_knowledge: "影库知识库-ES-0",
    query: {
      condition: [{"项目ID": ["6057"]}],
      view: {"星舟视频视图": {"param": "", "includes": ["腾讯最新热度值趋势"]}}
    }
  }]
)' --output json

# 同时查询多个视图
mcporter call 'szabot_tools.kb_search(
  recall_req_list: [{
    domain_knowledge: "影库知识库-ES-0",
    query: {
      condition: [{"项目ID": ["6057"]}],
      view: {
        "版权视图": {"param": "", "includes": ["疑似侵权量趋势"]},
        "星舟视频视图": {"param": "", "includes": ["腾讯最新热度值趋势"]}
      }
    }
  }]
)' --output json
```
