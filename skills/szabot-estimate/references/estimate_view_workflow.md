# 评估单数据查看工作流

> 🚫 **严格使用限制**：本工作流**仅适用于"查看评估单详细数据"场景**。当且仅当用户明确表达了查看某个评估单具体数据的意图时，才可加载并执行本文件。

---

## 全局执行规则

1. **底层操作静默**：MCP 调用过程不向用户展示，只呈现业务层面的信息。
2. **结构化展示**：以分组表格形式展示评估单数据，便于用户快速浏览。

---

## Step 1：获取评估单标识

从用户输入中提取 `apply_id`（评估单 ID）。

**获取方式（按优先级）：**
1. 用户直接提供评估单 ID
2. 从上下文中获取（如刚创建/刚查看的评估单）
3. 无法确定 → 询问用户提供评估单 ID

> `task_key` 固定为 `base_info_collection`，无需用户提供。

---

## Step 2：调用 getEstimateFormData 获取数据

> 静默执行，不向用户展示工具名和参数。

```bash
mcporter call szbotprojectformal getEstimateFormData --args '{"apply_id": <评估单ID>, "task_key": "base_info_collection"}'
```

**异常处理：**

> 按 `mcp_call_rules.md` §4 的错误分类与重试策略执行。

| 情况 | 错误类型 | 处理 |
|------|---------|------|
| 网络超时 / 后端不可用 | 网络失败 | 自动重试 3 次（2s→4s→8s），全部失败后告知用户 |
| 权限不足 | 权限问题 | 不重试，引导用户检查评估单权限 |
| 评估单 ID 不存在 | 业务逻辑 | 提示用户确认评估单 ID 是否正确，或引导用户先查看评估单列表 |
| 返回数据为空 | —（非错误） | 告知用户该评估单暂无数据 |

---

## Step 3：结构化展示数据

将返回的表单数据按业务分组展示：

> ⚠️ **字段名映射**：接口返回的字段名为技术名（如 `Foneline_intro`、`Fplay_name`），需要调用 `getEstimateFormSchema(form_id)` 获取 Schema，通过 Schema 中每个字段的 `title` 属性获取中文名（如 `"title": "一句话梗概"`），再用中文名向用户展示。`form_id` 从 `getEstimateFormData` 返回结果中获取。

> 🔴 **字段过滤约束**：**只展示 Schema 中定义的字段**。接口返回数据中不在 Schema `properties` 中的字段（如内部元数据、临时字段等），**一律不展示**。

### 3.1 分组规则

| 分组 | 包含字段示例 |
|------|------------|
| **基本信息** | 项目名称、上会主题、合作模式、所属工作室、是否IP、播出特征、是否独播、新媒体平台 |
| **剧集信息** | 集数、单集时长、正片总时长、一句话梗概、项目简介、题材类型描述、亮点 |
| **IP 信息** | IP 名称、使用名称、版权开始/结束时间 |
| **主创团队** | 项目负责人、导演、编剧、主演、其他演员、制作公司、公司制片人、监制 |
| **主要角色** | 角色名称、角色描述 |
| **人物关系** | 角色间关系说明 |
| **拍摄信息** | 拍摄地、预计开机/杀青时间、预计送审时间 |
| **版权信息** | 各类版权权益（新媒体发行权、传统媒体发行权、剧集改编权等） |
| **状态信息** | 表单 ID、表单版本、状态 |

### 3.2 展示规则

- 每个分组以 `###` 标题分隔
- 简单字段用表格（`| 字段 | 值 |`）展示
- 数组类型字段（如演员列表、IP 列表）单独用表格展示每个条目
- 空值字段显示"（未填）"
- 嵌套对象展开其关键属性
- **枚举字段展示**：若 Schema 中字段含 `enum` + `description`（如 `"枚举项: 1(重要且紧急), 2(重要不紧急)"`），展示时**必须将原始值映射为对应的中文名称**，禁止直接展示原始编码。例如接口返回 `"Fimportant_status": "1"`，应展示为"重要且紧急"而非"1"
- **风险提示**：若数据中包含风险标记（如制作公司有风险），用 ⚠️ 标识

### 3.3 元数据展示

在数据末尾附加元信息：

```
---
表单模板 ID: <form_id>
表单版本: <form_version>
当前状态: <status>
🔗 评估单链接: https://szgate.szabot.internal/x/r/doto9awl4o?applyId=<apply_id>
```

---

## Step 4：引导后续操作

展示数据后，提示用户可进行的操作：

```
您可以：
1. 修改某个字段 — 直接告诉我要修改的字段和新值
2. 查看其他评估单
3. 创建新的评估单
```
