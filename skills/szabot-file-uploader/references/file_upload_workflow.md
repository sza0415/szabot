# 文件上传工作流（File Upload Workflow）

## 概述

将用户提供的本地文件上传到影库文件系统，获取系统生成的 `fid`（文件唯一标识）。该 `fid` 是后续所有文件操作（解析、关联草稿等）的必要凭证。

## 全局执行规则

1. **自动化优先**：尽量自动从上下文中获取文件路径等信息，减少向用户提问。
2. **fid 是系统生成的**：`fid` 由上传接口返回，**严禁使用用户口头提供或手动输入的 fid**。任何需要 `fid` 的下游操作（如文件解析、草稿关联文件），都必须先完成本上传流程获取合法 `fid`。
3. **支持任意文件类型**：对文件格式没有限制，任何文件都可以上传。
4. **脚本路径**：上传脚本位于 `{skill_base_dir}/scripts/upload_file.py`。
5. **上传结果持久化**：上传成功后，必须将 `fid` 及完整的返回 JSON 保留在对话上下文中，确保下游工作流可以直接引用。

## 工作流步骤

### Step 1 — 获取文件路径

**目标**：确定待上传的本地文件路径。

**信息来源**（按优先级）：
1. 用户在对话中直接提供了文件路径
2. 用户通过 IDE 上传/附加了文件（从上下文提取路径）
3. 用户提到了文件名，可在工作区中搜索定位

**校验清单**：

| 校验项 | 规则 | 失败处理 |
|--------|------|---------|
| 文件存在 | 路径有效且文件存在 | 提示用户确认路径 |
| 路径格式 | 必须使用绝对路径 | 自动转换为绝对路径 |

**异常处理**：
- 文件不存在 → 提示用户检查路径是否正确
- 用户未提供文件 → 询问用户提供文件路径或直接上传文件

### Step 2 — 执行上传

**目标**：调用上传脚本，将文件上传到影库文件系统。

**执行命令**：

```bash
cd {skill_base_dir}/scripts && python3 upload_file.py /absolute/path/to/file.pdf
```

> ⚠️ 文件路径必须使用**绝对路径**。如果用户提供的是相对路径，需先转换为绝对路径。

**脚本执行流程**：
1. 校验文件存在性
2. 计算文件大小（`size`）和 MD5 哈希（`h`）
3. 推断 MIME 类型（`mimeType`）
4. 调用 `PUT /ai/file/upload` 接口

**上传请求参数**：

| URL 参数 | 说明 |
|---------|------|
| `size` | 文件大小（字节） |
| `h` | 文件内容 MD5 校验值 |
| `name` | 固定格式 `mm/{fid}.{ext}` |

**标准输出**（JSON 格式）：

```json
{
  "fid": "fid_xxxxxxxxxxxxxxxxxxxxxxxx",
  "name": "策划案v2.pdf",
  "size": 1048576,
  "md5": "d41d8cd98f00b204e9800998ecf8427e",
  "mimeType": "application/pdf",
  "fileType": "pdf",
  "uploadName": "mm/{fid}.pdf"
}
```

**关键字段说明**：

| 字段 | 说明 |
|------|------|
| `fid` | 文件唯一标识，**由系统生成**，后续解析、关联草稿等操作的必要参数 |
| `name` | 原始文件名 |
| `size` | 文件大小（字节） |
| `md5` | 文件内容 MD5 校验值 |
| `mimeType` | 文件 MIME 类型 |
| `fileType` | 文件类型分类（如 `pdf` / `word` / `ppt` / `image` / `video` / `other` 等） |
| `uploadName` | 上传时使用的远端文件名 |

### Step 3 — 结果处理

#### 上传成功（退出码 = 0）

1. 从标准输出 JSON 中提取 `fid` 及完整信息
2. 向用户展示上传结果摘要：

```
✅ 文件上传成功！

| 字段 | 值 |
|------|-----|
| 文件名 | 策划案v2.pdf |
| 文件类型 | pdf |
| fid | fid_xxxxxxxxxxxxxxxxxxxxxxxx |
| 文件大小 | 1.0 MB |
```

3. **将 `fid` 和完整返回信息保留在上下文中**
4. 提示用户可进行的后续操作：
   - 文件解析（提取结构化内容用于创建项目）
   - 关联到草稿（作为附件关联到影库项目草稿）

#### 上传失败（退出码 ≠ 0）

| 退出码 | 含义 | 处理方式 |
|--------|------|---------|
| `1` | 文件不存在 | 提示用户检查文件路径 |
| `2` | 其他错误（接口异常等） | 查看 stderr 输出，展示错误详情 |

**常见错误及处理**：

| 错误场景 | 处理方式 |
|---------|---------|
| 文件不存在 | 提示用户确认路径是否正确 |
| 网络/接口错误 | 建议用户稍后重试 |
| 响应中缺少 fid | 提示接口可能异常，建议重试 |

## 与下游流程的衔接

上传成功后获得的 `fid` 可用于：

| 下游操作 | 技能 | 说明 |
|---------|------|------|
| **文件解析** | `szabot-file-parser` | 基于 `fid` 创建解析任务，提取文件内容用于项目创建 |
| **草稿关联文件** | `szabot-project` | 将 `fid` 作为 `file_id` 关联到项目草稿 |

> ⚠️ **重要提醒**：下游操作中使用的 `file_id` / `fid` **必须来自本上传流程的返回结果**，不可使用用户自行提供的 ID。
