# 素材 ID 查询播放链接（cms_search_assets）

当查询结果中包含素材 ID，且用户需要查看素材时，调用此工具获取播放链接。

## 调用方式

```bash
mcporter call 'szabot_data_query_svr.cms_search_assets' --args '{
  "material_id": ["素材ID1", "素材ID2"]
}'
```

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `material_id` | string[] | 是 | 素材 ID 列表，支持一个或多个 |

## 返回结构

```json
{
  "assets": [
    {
      "id": "素材ID",
      "title": "素材标题",
      "url": "素材播放/访问链接"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `assets[].id` | 素材 ID |
| `assets[].title` | 素材标题 |
| `assets[].url` | 素材播放/访问链接 |

## 输出格式

**单个素材**：

```
素材标题：{title}
链接：{url}
```

**多个素材**（表格形式）：

| 素材ID | 标题 | 链接 |
|--------|------|------|
| {id} | {title} | [点击访问]({url}) |

> ⚠️ 如果某些素材 ID 未在返回结果中，告知用户该素材未找到。不得编造链接。
>
> ⚠️ 返回的 `url` 必须**完整原样**输出给用户，**禁止**遗漏查询参数、截断路径或以任何方式篡改链接。
